# M4 本地验收

2026-11-19。验证环境为独立回环 MySQL 8.4、开发 Mock 服务、FFprobe 和 Chrome。服务使用合成作品及测试账户。

## 管理端

- 从 `web/admin` 构建并嵌入 Go 可执行文件。浏览器验证深链接登录、角色导航、下载域名登记、平台维护切换、工单回复、新建管理员、配置发布和按历史值发布新版本。验证了窄屏导航及后端拒绝无权限请求。
- 通过 Vite 开发入口验证 `/admin/v1` 代理和 Origin 校验。嵌入版与代理都使用管理端会话 Cookie。
- MySQL 集成测试覆盖目录、配置、观测、账户、反馈与审计。验证乐观锁冲突、危险参数拒绝、反馈敏感字段授权和脱敏审计。平台切换后的解析拒绝和公共配置刷新也经浏览器联调验证。
- 下载域名占比以各主机的累计出现次数加权，按当前登记状态计算。配置表标明重启生效与预留键。
