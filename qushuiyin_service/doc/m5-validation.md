# M5 本地验收记录

2026-11-19。使用 Windows、18 个可调度 CPU、约 23.5 GiB 主机内存、独立 MySQL 8.4.13 和本地 Mock。生产启动演练使用第二个隔离数据库。所有媒体均为合成样本。

## 部署与回滚验证

- Windows 本地验证 MySQL 8.4 模板 `--validate-config`。Nginx 1.30.7 在替换回环端口、Linux 路径和临时证书后通过 `nginx -t`，并实际代理 TLS 请求。证书按测试 CA 显式校验。
- 生产演练用独立数据库迁移账号和只有 DML 权限的运行账号。生产拒绝 Mock，平台初始关闭。管理端按 Host 提供嵌入页，Mock 登录凭证被拒绝。微信 code2Session 使用离线响应测试。
- 用合成计数触发了出站临近保护线、未登记主机占比和直连回退告警。文件清理、磁盘保护、超期任务和来源熔断有 Go 回归。实际告警接收通道及 systemd 主机启停待 H6。
- Go 全量测试、`go vet`、Vue 构建、嵌入的 Linux amd64 交叉编译、小程序 TypeScript 检查、Mock API 与小程序回归通过。各发行机的 systemd 单元、生产 HTTPS 域名、真实微信凭证以及发布/回滚需在负责人环境逐项确认。
