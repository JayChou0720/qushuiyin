# M2 主流程验证记录

## 范围与结论

## 持久化与恢复

| 检查项 | 方法与结果 |
| --- | --- |
| 受理与幂等 | 对象与幂等记录在同一事务提交；重新构造服务后，同键同参数返回原 ID，不同参数返回 409。 |
| 解析租约 | MySQL 原子领取、递增 claim_seq；手动推进过期租约后重新领取，旧 worker 返回不产生结果，新 worker 正常提交。 |
| 取消竞争 | 调用中取消任务，迟到成功结果不发布。 |
| 批次恢复 | 重建服务后可查询已有批次，新的媒体 worker 可继续准备；重试清除旧租约并推进领取序号。 |
| 源信息期限 | 到期清除分享链接、历史链接和媒体候选密文；保留不含源地址的标识以返回明确过期响应。重放原幂等键返回 410。 |

恢复测试使用独立回环 `qushuiyin_test` 和新建服务实例，不将其表述为进程强杀、机器掉电或备份恢复测试。

## 中转、授权与文件清理

| 检查项 | 方法与结果 |
| --- | --- |
| 文件校验 | 实际 GET、累计字节上限、声明大小与 MIME、魔数；JPEG/PNG 完整解码与像素限制；MP4 经真实 ffprobe 验证 H.264/AAC。伪装 HTML、截断图片、MIME 冲突及超限文件被拒绝，无可下载残片。 |
| 旧媒体租约 | 阻塞取回期间更换领取序号，旧 worker 不创建用户授权；新 worker 复用已校验文件并完成。 |
| 共享与隔离 | 两个用户、三个批次只取回一份文件；用户获得独立授权。另一用户批次不可访问；删除一个用户后，其旧票据失效，另一用户仍可下载。 |
| 票据与 Range | 签名绑定用途、对象、会话、批次、期限及随机票据 ID；支持 HEAD 和单段 Range。12 字节响应按实际 12 字节结算 MySQL 出站额度。 |
| 容量与连接 | 准备前预留缓存预算；下载按全局、用户和票据限制连接，并按配置设置发送期限。 |
| GC | 活动下载保护文件；授权和文件均过期且连接结束后，删除物理文件。扫描过期 `.part` 和未登记孤立文件。 |

## 复查命令与剩余工作

### 直连优先（第一块）

已接入 `direct_preferred/relay_only/copy_only` 策略；最终跳转主机记录到 download_domain，直连地址经轻量探测后加密存储。未登记主机共享整批 `direct_reparse_attempts`，源失效刷新使用独立的一次预算；重试不重置计数。图片对应关系无法确认时返回 CONTENT_CHANGED。

MySQL/Mock 验证：已登记主机不取回完整文件；地址持久化后可恢复；直连回退幂等且只允许一次；超过中转上限的文件只开放本人复制；复制次数跨服务状态写入每日额度；少量回退不改主机状态，达到阈值转 review。发放与回退统计不含源地址。A67、A68、A70、A72 的服务端分支通过；A66 正式版真机直连下载及 A68 真机回退：**待负责人验证**。

配置独立 `MYSQL_TEST_DSN`、`FFPROBE_TEST_PATH` 后，在后端目录运行 `go test -p 1 -count=1 ./...`、`go vet ./...`。启动 Mock 后运行 `node qushuiyin_service/scripts/smoke-mock.mjs 58704`；小程序运行 TypeScript `--noEmit` 检查。

### 预览与缩略图（第二块）

preview-tickets 按资源归属签发，结果查询的预览字段恒为 null；默认关闭直连预览。视频接口连接真实源并输出有限单段 Range，每张票据累计不超过 preview_max_bytes。未知总长或无法验证 Range 的源保守拒绝预览，不影响保存。缩略图首次请求时生成最长边 480 的 JPEG（边长、质量、排队期限取配置），跨用户共享；大图使用已校验原图。图片解码和缩放共用 image_convert_workers，不创建 media_object。

MySQL 与离线响应验证：发票时不取回完整媒体、HEAD、Range、累计字节、每日出站结算、用途签名隔离、资源版本变化、归属与会话撤销；缩略图等比缩放、缓存命中、像素与 worker 上限通过。A18、A19、A71 的服务端分支通过；直连预览和播放器、图片组件的生产真机表现：**待负责人验证**。direct_preview_enabled 保持默认 false。

启动服务回归暴露解析领取与发布的锁竞争，已把领取限定为任务行锁并采用 READ COMMITTED；到期处理独立提交，空队列也保存终态。发布遇到死锁只在期限内重试数据库事务，并再次检查租约。四个后台 worker 连续处理失败样本与空队列到期回归通过，没有增加上游请求重试。

当前真实接口仅开放回环开发环境。WebP 转换、活动保存操作租约及完整运营指标仍待后续接入；生产登录、域名登记和 iOS/Android 相册保存另行验收。WebP 暂明确返回不支持格式，不以 Mock 样本替代真实输出。
